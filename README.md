CSS para personalizar el fondo de Claude.ai con tu propia imagen y efecto vidrio en la barra lateral, el composer y los menús.

Para aplicar el tema instala la extension de Stylus o la de tu preferencia y aplica el .css a claude.ai.

Y por ultimo si necesitas cambiar la imagen de fondo o la de foto de perfil solo cambia la url, tiene que ser una url directa a la imagen por ejemplo: https://i.imgur.com/rNG4Pql.png y no asi: https://imgur.com/rNG4Pql. Puedes usar Wallhaven, imgur, etc lo que sea de tu preferencia.
